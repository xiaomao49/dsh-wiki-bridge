# Vault 模板

开箱即用的 Obsidian vault 约定模板，配合 WikiBridge 插件使用。

## 使用

1. 把 `_约定.md` 复制到你的 Obsidian vault 根目录
2. 按需创建目录结构：`收件箱/`、`归档/`、分类目录（`Caelestia/` `系统维护/` `网络/` `应用/` `服务/` `开发/`）、`首页.md`
3. 在 DSH 设置页（设置 → WikiBridge）配置 vault 路径并保存

## 定制

- **分类目录**：按需增删（同步修改插件 `lib/index.js` 的 `CATEGORIES` 与首页分组标题）
- **标签白名单**：按需增删（同步修改 `TAG_WHITELIST`）
- **遗忘阈值**：设置页"过时阈值（天）"调整（默认 90 天，最小 7 天）

## 与插件约定的一致性

插件内建的约束（frontmatter 生成、白名单校验、收件箱铁律、归档区排除）都以本模板的规范为准绳；修改模板即修改知识库的"宪法"，记得同步插件常量。
